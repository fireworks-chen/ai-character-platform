# SillyTavern 能力核对（本地源码 1.19.0）

核对对象：`apps/sillytavern` 本地源码，package 版本 `1.19.0`。结论按“可直接复用 / 可通过扩展或自定义前端实现 / 需要星语业务层”区分。

| 星语能力 | SillyTavern 状态 | 结论 |
|---|---|---|
| 角色卡 V2/V3 导入导出 | 原生支持 character card / spec-v2，内容管理器支持角色卡与嵌入 lorebook | 可直接复用协议与解析器 |
| 对话、历史记录、消息编辑/删除 | 原生聊天存档、消息操作、上下文管理 | 可直接复用核心 |
| 分支、重试、swipe、多版本回复 | `public/scripts/bookmarks.js` 有 branch snapshot，聊天代码有 swipe 数据 | 可直接复用能力，星语负责换成自己的 UI |
| 群聊 | 常量和 prompt converter 都包含 group chat 支持 | 可直接复用核心 |
| Persona | 原生 persona 配置、头像和 persona lore 关联 | 可直接复用核心 |
| World Info / Lorebook | 原生 World Info、lorebook 导入、扫描和注入；支持 character book | 可直接复用核心 |
| Author’s Note / 导演指令 | `public/scripts/authors-note.js` 原生支持角色级和默认 Author’s Note、深度、频率、插入位置 | 可直接复用，星语可命名为导演指令 |
| Preset / system prompt / instruct | 原生 prompt 预设和生成参数 | 可直接复用核心 |
| 关系值、状态栏 | 没有星语这种面向用户的关系数值和状态面板 | 需要星语数据模型 + 前端，数值可注入 prompt |
| 剧情选项 | 没有原生剧情选项生成/选择 UI | 需要星语业务层，选项内容可由模型或规则生成 |
| 刷新开场白 | 可以通过删除/重生成消息或扩展实现，但没有星语同名产品按钮 | 星语前端封装操作 |
| 创作者中心、角色草稿、审核、公开发布 | 没有 SaaS 创作者中心和审核流 | 必须自建 |
| 公开角色广场、作者主页、关注 | 没有跨用户公开社区关系模型 | 必须自建 |
| 点赞、评论、收藏 | 没有星语式社区互动 | 必须自建 |
| 签到、任务、聊天奖励、积分 | 没有业务积分/任务/结算系统 | 必须自建 |
| 邀请返佣 | 没有邀请关系和佣金账本 | 必须自建 |
| 小说、章节、阅读社区 | 没有小说发布/阅读/章节产品 | 必须自建 |
| 游戏卡、存档、小游戏运行时 | 可用扩展或自定义页面接入，但不是核心能力 | 需要星语 Miniapp 数据模型和存档服务 |
| 图片生成、扩展脚本 | 支持扩展和自定义脚本，具体模型由接入方提供 | 可复用扩展机制，星语负责权限和计费 |

## 结论

SillyTavern 适合作为“聊天内核”：角色卡、上下文、Persona、World Info、Author’s Note、群聊、分支和重试都可以复用。它不适合作为星语的完整社区产品后端；创作者中心、公开内容、社交关系、积分任务、返佣、小说和游戏存档需要保留在星语自己的 API 与数据库中。

## 当前侧栏约束

PC 和移动端产品导航统一收敛到：

- 角色
- 聊天
- 发现
- 我的
- 创作中心

World Info、Persona、导演指令等作为聊天页右侧上下文工具进入，不单独占据一级导航。
