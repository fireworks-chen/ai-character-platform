# 星语 AI 角色聊天

独立用户前端、Ant Design 管理前端、两套 NestJS API、Docker PostgreSQL 和 SillyTavern Core。两套 API 直接使用同一个 PostgreSQL 数据库，互不调用对方的业务接口。

## 启动

需要 Node.js 22+、pnpm 和运行中的 Docker Desktop。工作区已经生成本机 `.env`，不要覆盖它。新机器可以复制 `.env.example` 并填写数据库、加密和 Core 密码。

```powershell
pnpm install
pnpm db:start
pnpm build
```

分别在四个终端启动：

```powershell
pnpm dev:api
pnpm dev:admin-api
pnpm dev:web
pnpm dev:admin
```

| 服务 | 地址 |
| --- | --- |
| 用户前端 | http://localhost:4173 |
| 用户 API | http://localhost:3000/api/v1 |
| 管理前端 | http://localhost:4174 |
| 管理 API | http://localhost:3100/api/v1/admin |
| SillyTavern Core | http://127.0.0.1:8000，仅供服务端使用 |
| PostgreSQL | 127.0.0.1:5432 |

首次启动会创建一个真实管理员账号。未指定初始密码时，随机凭据保存在 `.data/admin-credentials.txt`。管理端使用邮箱和密码登录，没有演示令牌；普通用户可在用户端注册，也可由管理员创建。数据库初始没有角色、模型、普通用户、积分、会话、图片或订单。

## 功能

- 后台角色新增、完整编辑、发布/下架、删除、搜索，以及 SillyTavern JSON / PNG 角色卡导入和 V2 JSON 导出。
- 角色封面支持 PNG/JPEG/WebP 上传、本人已有图片选择、后台已配置的生图模型生成与预览。图片内容保存在 PostgreSQL，生成请求可幂等重试；后台制作素材不扣用户积分，供应商生成费用按其渠道计收。
- 用户创建、编辑、密码重置、停用、删除；超级管理员、内容运营、只读审计员、普通用户四种服务端权限。
- 积分增加/扣减、原因记录、重复请求幂等、余额不能为负、冻结与结算、失败退款、超时任务回收、账本查看与 CSV 导出。
- 多聊天/生图模型配置、默认模型、启停、供应商连接测试，以及输入/输出/缓存命中/缓存写入单价、单张图片积分和计费计算器。密钥加密保存在 PostgreSQL，查询接口与日志不返回密钥。
- 同类首个启用且已有密钥的模型自动设为默认；模型列表支持一键切换默认。替换默认后才可停用或删除原默认模型，未指定默认时会显示具体配置提示。
- 模型编辑器支持用地址和密钥拉取供应商 `/models` 列表，搜索选择或手动输入；编辑已保存配置时可使用后台密钥拉取，修改供应商地址后需重新输入密钥。
- 后台「测试连接」会在读取 `/models` 后再通过 SillyTavern Core 发起一次最小真实聊天请求；仅能读取模型列表但没有可用上游时会明确报错，不再显示“连接成功”。
- 供应商地址只填写域名时自动补齐 `/v1`，已有自定义 API 路径保持不变。拉取成功后编辑器显示实际 API 地址；聊天、生图、连接测试同样使用规范化后的地址。认证错误、网页响应、无效 JSON 和网络超时有分别的提示。
- 充值/会员套餐新增、编辑、上下架、删除；会员天数、积分和 Token 计费折扣；真实订单查询、明细及导出。
- 自有支付的 HTTP + HMAC 适配器配置、创建订单、验签回调、金额核对、支付事件防重和会员/积分入账。适配器协议见 `docs/payment-adapter.md`。
- 操作日志包含操作人、目标、修改前后值、时间和原因；支持搜索、详情和导出。
- 操作日志及 CSV 显示中文操作名；用户对象使用邮箱账号，角色/模型/套餐显示名称，系统任务和支付到账显示关联账号。原始操作代码和对象 ID 保留在审计数据中，图片内容不重复写入日志。
- 用户端登录注册、动态角色搜索/性别/标签筛选、收藏、角色详情、创建聊天、会话搜索/重命名/置顶/归档/恢复/删除、聊天导出和文本附件导入。
- 聊天调用真实 SillyTavern Core，生图调用管理员配置的图片供应商。按实际用量扣费，未配置或无实际用量时明确报错，不生成假回复或估算扣费。
- 聊天支持真实 SSE 流式输出、即时消息气泡、停止生成、Markdown 段落/角色动作/代码块，以及 Enter 发送、Shift+Enter 换行。用户滚动查看历史时不会强行拉回底部；切换会话自动取消生成。
- 供应商返回推理数据时显示真实「正在思考」状态，首段正文前显示等待秒数；推理内容不作为聊天正文保存。日常对话默认一至三句，用户明确要求长文时展开。上游模型的排队和思考可能延迟首段正文，流式传输不等于即时完成推理。
- 流式请求通过 SillyTavern 自定义兼容源转发 `stream_options.include_usage`，完成后才将消息和实际输入/输出/缓存用量一起写入 PostgreSQL、结算积分。取消、断连、缺少实际用量或供应商错误时退回预留积分，未完成文字仅暂留当前页面，可用同一请求 ID 重试，已完成请求不会重复扣费。部署反向代理时须关闭该 SSE 路径的响应缓冲。
- 真实图片生成/上传、预览、收藏、下载、删除和按会话筛选；图片内容保存在 PostgreSQL，供应商短期 URL 不会作为唯一存储。
- 个人中心使用真实昵称、会员、余额、收藏数和图片数；设置支持改昵称、改密码和退出；充值、会员、消费记录为独立可操作页面。
- 两端切回窗口和定时刷新数据库状态，管理端发布角色、调整积分或改会员后用户端同步读取。

用户和角色删除为软删除，历史消息、订单、账本和审计记录保留。删除不能撤销已发生的支付或消费。

## 验证

```powershell
pnpm test:all
```

集成测试启动真实 NestJS 服务连接 PostgreSQL，验证权限、增删改、跨 API 联动、缓存计费、幂等扣费、失败退款、支付验签、图片存储及重启持久化；还调用 Docker 中的真实 SillyTavern Core。测试供应商仅存在于测试进程，运行业务服务不包含任何模拟生成逻辑。Playwright 使用独立测试端口与 `ui_admin_test` / `ui_web_test` schema，测试数据在结束时清理，不进入正式 `public` schema。

## 配置与边界

真实聊天和生图需要在管理端配置有效供应商，流式聊天要求渠道支持兼容 Chat Completions SSE 和最终实际用量；模型列表可读取不代表生成渠道可用。支付适配器已经实现并验证内部协议，但用户自有渠道的原生 API 文档尚未提供，因此没有宣称已完成该渠道的真实收款联调。没有自动续费、真实支付退款接口或群聊；这些不应被当作已完成能力。

当前角色卡导入保留角色设定、性格、场景、示例、开场白和标签。完整世界书、Lorebook、扩展插件、V3 多媒体资源等 SillyTavern 高级能力尚未移植到上层 UI。

`apps/api/src/domain-schema.sql` 与 `packages/data/src/database.ts` 对应实际运行表结构。服务启动执行幂等建表/迁移；生产使用数据库迁移账号与业务账号分离、HTTPS、备份、固定 Docker 镜像版本和受控管理员引导环境。修改加密密钥前需要迁移已有密文，直接换钥会导致供应商密钥无法解密。
